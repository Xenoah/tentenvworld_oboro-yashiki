# 木刀・HP・スタミナ（v1.4）

木刀は非致死性の退路確保用です。J、画面左下の木刀ボタン、またはXR右グリップを握ったまま右トリガーで一振り。連打は750ms間隔、22気力を消費します。正面100度・水平2.4m以内・高低差1.6m未満・庭石や屏風を挟まない忍者一体へ40の体勢ダメージ。命中で950msひるみ、体勢100を3打で崩すと8秒間止まります。その後は回復して巡回へ。PvP、流血、敵討伐点はありません。

HPは100。忍者は既存の警告時間の後、見習い35／忍び50／上忍100のダメージを与えます。被弾後1.8秒は複数の忍者からの連続ダメージも無効。警告を再開してから次の攻撃です。HP0で、見習い・忍びは従来の牢へ、上忍は全員失敗。仲間の救出・自動脱出でHPと気力を全回復。玄関への帰還ボタンではHPを回復できません。途中参加者は100から開始します。

気力は100。地面を実際に走ると毎シミュレーション秒18消費し、消費後650ms休むと毎秒15回復。0で息切れ、30に回復するまで歩行速度になります。木刀にも同じ気力を使用。低FPSでは既存物理と同じく更新時間を制限するため、壁時計の秒数どおりではありません。

同梱の公式クライアント拡張はデスクトップとXRの走行倍率を実際に制限します。標準TenTenVへ`.ttvw`単体importした場合は気力と攻撃費用を共有しますが、ダッシュの速度制限はありません。必要なoptional APIと固定upstreamへの適用は [CLIENT_EXTENSION.md](CLIENT_EXTENSION.md)。

被弾は赤茶の画面縁・HPバー・メッセージで通知。縁色を標準／弱／切に変更できます。視点揺れはなく、XRでは画面縁を使わず浮遊ステータスと敵の体勢表示を使います。XR右ボタンの静音着地操作は従来どおりです。木刀の光跡と命中輪郭は全クライアントの同じ共有イベントを描画し、1.5秒後に破棄します。木刀音・被弾音は既存「音：入」に従い、マイクを要求しません。

ホストが送信者の参加・run・捕縛・最新pose・向き・射程・遮蔽・気力・クールダウン・単調増加の要求番号を検査します。クライアント申告のtarget/damage/positionは使いません。HPと忍者体勢は共有snapshotで途中参加やホスト交代へ継承。救出後も受理済み要求番号を保持し、遅れた攻撃の再実行を防ぎます。再開始は傷・気力・攻撃番号・光跡・息切れを初期化します。

これは選出ホストと参加者の既存pose通信を使う協力ゲームです。参加者が改造クライアントでposeや共有ストアそのものを偽る競技用の耐チート保証ではありません。別端末・実親サーバー通信とVR実機は未検証。Pagesでは同一ブラウザのBroadcastChannelのみで、環境別VCは次段の未完了項目です。
