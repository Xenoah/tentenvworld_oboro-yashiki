# 朧の屋敷 — OBORO v1.7.0

場面別のオリジナルBGMと多彩な効果音を追加しました。v1.6の5室ミッションと最終の庭、従来の戦闘・移動・協力を維持しています。

- 探索・5部屋・追跡・脱出・敗北の9曲×雅／影の2編成。旋律・音階・編成・リズムを変更し、約1.2秒でクロスフェード。
- 26種×4パターンのSE。材質別の足音・着地、木刀空振り／命中、被弾、取得、成功失敗、扉など。連打制限と同時発音上限で音量過大と同一音の反復を抑制。
- BGM／SEの個別音量・ミュートと任意曲選択。ユーザー操作後に再生。背景タブでは停止、復帰は現在の場面から再生。再開始・退出時に音源を破棄。
- 受信VCがある間はゲーム音量を抑制。実VC音声はゲーム用コンプレッサー／音量設定を通しません。マイクを自動で開きません。
- 72秒の音楽試聴WAV、約79秒のSE試聴WAV、再現可能な生成器と解析表を追加。全音源は自作合成、AGPL-3.0-only。外部録音・外部AI API・新課金なし。

48単体試験、型検査、音源再生成一致、実Chromiumのゲーム音声経路と既存ミッション／協力／戦闘／VC回帰を検査。2曲＋12SEの実レンダリングでピーク約0.705。全ループ・全SEの波形を数値確認していますが、聴感・実スピーカー・実VR／Android・実リモート通話は未検証です。Windows指定サイトQAは停止中。

Pagesはソロと同一ブラウザの最大4タブで、別端末通信や通話バックエンドを含みません。標準SDK単体では特殊移動は足場／ワープ互換経路です。

配布はsource ZIP、ttvw、Pages ZIP、最終SHAの実プレイ3画像、2試聴WAV、撮影／音源／ビルド情報、SHA256SUMS、ノートとライセンスの計15ファイル。旧タグ・旧配布物は保持します。
