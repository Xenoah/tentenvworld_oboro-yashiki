# 朧の屋敷 — OBORO v1.1.0

月夜の屋敷に柔らかな灯りと素材の反射を追加しました。画面下の「映像」からグローの標準／軽量／切、強度、細部の陰影と灯りを調整できます。

- 実際の建築形状へ約199万本の光線を計算し、局所AOと15灯の静的な直接拡散光を頂点データへ保存。多重反射GIやシーン全体のライトマップではありません。
- 木・漆・瓦の粗さとクリアコート、真鍮の反射、PMREMによる自作の月夜の反射環境。
- 閾値付きの柔らかなBloomとFXAA。軽量表示は灯籠のHaloだけを描画。携帯端末・低解像度では軽量化し、XR中はにじみを無効化。
- ベイク再生成・ハッシュ検査・比較画像・実装範囲をdocs/LIGHTING.mdへ収録。

ゲームの五印・特殊移動・忍者・勝敗・再開始は維持しています。旧v1.0.1タグと配布物は変更していません。

## 操作と検証範囲

玄関で難易度を選んで開始。WASD移動、クリックで視点操作、E/クリックで調べる、Space上昇、Q下降。「快適移動」でワープ足場と自由移動を切り替えます。

型検査、13テスト、ベイク整合検査、公式CLIビルド、Chromiumの一周・4タブ共有・途中参加・重複鍵・ホスト移譲・勝敗・再開始、映像設定とWebGL失敗案内を検査します。長い移動はdebug engineのテレポート、仕掛けは実Clickable callback、敵と時計は配置fixtureも使用。全行程を画面クリックだけで操作した検査ではありません。

**Pagesはソロと同一ブラウザ内のタブ間協力デモです。別端末オンライン協力とVCのバックエンドは含みません。** VR実機、実Android、実WebRTC/TURN/VC、公開URLでの3D通し検証は未実施。ソフトウェアGPUのFPSから実機性能を保証しません。

公式基盤: TenTenV `97e9bc120f4f977e0a3cfdb79379391e236f25e2` / SDK 0.1.1。AGPL-3.0-only。自作データは同ライセンス、AkaneアバターCC0、LINE Seed JPはOFL 1.1、依存の帰属は同梱ライセンス参照。
