# 朧の屋敷 — OBORO v1.3.0

スピード感・ゲーム感・カジュアル感を足す更新です。公開済みv1.2.1の静音着地・足音・移動ブラー・砂埃と、離陸確認を強化した試験を保持します。

## 不具合修正
- 書院と水牢の間、水牢の奥、北側の帯、南西の庭に床がなく、虚空へ落ちて自動帰還（-150点）が繰り返し発生していた問題を修正。南側に外壁を追加。0.4m格子で全域の床を検査する単体テストを追加。
- 書院の壁の当たり判定が障子より長く、縁側と東の入口を塞いでいた問題を修正。隠し部屋は回転扉からしか入れないよう仕切りを追加（扉の脇から回り込めた）。
- 脱出門のボタンが裏向きで文字が見えなかった問題を修正。
- 忍者の巡回ルートが庭石を横切り、2体とも中央で行き来するだけになっていた問題を修正（障害物を避けた外周ルート、2体目は逆回り）。
- 竹林が跳躍の庭・天井回廊の壁の内側に生えていたのを外へ移動。
- 標準クライアント：互換足場を見える板に、水牢は水底へ直接、操作表示をクリック中心に整理。星蔵の「取得済」と戻るボタンの重なりを解消。

## 新しい遊び
- **タイムアタック**：見習い8:00／忍び5:00／上忍4:00、印ごとに+30秒（上忍+20秒）。3・2・1の合図、印ごとの区間タイム、自己ベスト（得点・タイム）。
- **触れるだけ**：印・星・水門・脱出門・小判・煙玉はSDKのTriggerZoneで反応（クリックも可）。ワープは光る輪の足場に。縁側の左右に南北をつなぐ縄（近道）。
- **太鼓BGM**：合成音の太鼓が残り2分・1分で速まり、追跡中は心音。残り1分は画面の縁が赤く脈打つ。
- **忍者の視界**：前方100/110/120度の扇形＋近距離1.8mで発見。足元に扇形を表示。屏風2枚を遮蔽物として追加。
- **煙玉**：中庭に3個。触れて拾い、Bで周囲6mの忍者を3秒止める。
- **毎回変わる解き方**：札の順（屋敷内3か所のどこかの掛軸に）、星の順、4か所から選ばれる水門2つ、印の置き場所、小判8枚の配置がラウンドごとに変化。ホストの位置検証も同じ配置で行う。
- **小判**：部屋100／中庭200／中央300点。
- **取得演出**：印の色の光の粒、画面のフラッシュ、HUDの印がはまるアニメーション、効果音。
- **牢**：見習い・忍びでは捕まった人だけ牢へ（200点×難易度倍率の減点）。仲間が錠に触れるか、ソロ12秒／20秒（複数人は最大45秒）で出られる。上忍は従来どおり全員敗北。
- **ナビ**：足元の矢印と光の柱で次の目的地、上部に「次：…」。
- **疾風モード**：ランダムな3部屋の印だけを3分で集める。
- **HUD整理**：上部1本（残り時間・必要な印・区間タイム・得点）、トースト、細いツールバーだけに。

## 統合時の追加修正

- debug=1のときだけ配置フックを公開し、戻り値は深いコピー。外から本来の配置を変更できないようにしました。
- 牢にいる途中に再開始しても、全員が安全な玄関へ戻ります。開始合図前・収容中は局所ワープを無効化。
- 再開始のカウントダウンやワープ直後の小さな落下で、ジャンプブラーが誤って出ないよう修正。実接地後に移動演出を再開。
- 背景タブ復帰時、太鼓が過去の拍をまとめて鳴らさないよう補正。
- 2人の実コマンド送信を観測する重複取得試験、星ごとの到達確認、乱数40種×2モード、牢復帰の実ブラウザ試験を追加。
