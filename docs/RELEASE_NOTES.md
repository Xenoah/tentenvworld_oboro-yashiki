# 朧の屋敷 — OBORO v1.2.0

ダッシュとジャンプに控えめな周辺ブラーを追加し、着地の音が忍者の捜索につながるようになりました。下降中、地面まで約75cmで **X** を一度押すと静音着地。早押しや押し忘れでは足音が響きます。

- Pointer Lockが使えない環境では中央のドラッグ操作ボタンから通常の左ドラッグ視点＋E操作へ切替可能。ブラウザ設定や権限を変更しません。
- Shiftでダッシュ、Spaceでジャンプ。緑の着地ボタンで受付タイミングを表示し、成功／失敗を知らせます。
- 足音は主催者が姿勢・床材・落差から判定。遮蔽物・室内・高低差で減衰し、忍者は聞いた方向へ向かって捜索します。音のミュートでもAIの聴覚は変わりません。
- 中庭の砂地では走行・離陸・着地に砂埃。飛石・板床・畳・水中では発生しません。最大160粒、追加1 draw。
- 移動ブラーは「映像」で0〜60%を調整可能、初期28%。XR・携帯端末・低解像度では無効。照準中心を保ち、視点の揺れは追加していません。
- 共有された足音ID・着地履歴・捜索状態を途中参加とホスト交代で引き継ぎ、再開始では入力・粒子・ブラーをリセット。

v1.1のベイク・照明・素材と五印の脱出ゲームを維持しています。旧タグと配布物は変更しません。攻撃・HP・スタミナとVC音響は後続版の対象です。

## 操作と検証範囲

玄関で難易度を選んで開始。WASD移動、クリックで視点操作、E/クリックで調べる、Space上昇、Q下降、Shiftダッシュ、X静音着地、H三人称。「快適移動」でワープ足場と自由移動を切り替えます。参加者は全員同じ公開版を再読込してください。

型検査、18テスト、ベイク整合検査、公式CLIビルド、Chromiumの一周・4タブ共有・途中参加・重複鍵・ホスト移譲・勝敗・再開始を検査。追加試験は実キー入力の着地・失敗音→捜索・砂/石・ブラーOFF・位置付き音声再生と3タブの騒音共有/移譲。長距離はdebug teleport、仕掛けは実Clickable callback、敵と時計は配置fixtureも使用。着地結果や敵の捜索modeを成功値へ直接変更していません。

**Pagesはソロと同一ブラウザ内のタブ間協力デモです。別端末オンライン協力とVCのバックエンドは含みません。** VR実機、実Android、実WebRTC/TURN/VC、公開URLでの3D通し検証は未実施。ソフトウェアGPUのFPSから実機性能を保証しません。姿勢は元のクライアント管理であり、競技用のサーバー権威型アンチチートではありません。

公式基盤: TenTenV `97e9bc120f4f977e0a3cfdb79379391e236f25e2` / SDK 0.1.1。optional姿勢速度を公開する同梱パッチはprotocol形式を変更しません。AGPL-3.0-only。自作データは同ライセンス、AkaneアバターCC0、LINE Seed JPはOFL 1.1、依存の帰属は同梱ライセンス参照。
