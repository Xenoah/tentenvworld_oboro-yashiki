# 朧の屋敷 — OBORO v1.6.0

室内から始まり、歪んだ五つの部屋のミッションを越え、最後に夜風の庭から脱出する新モードを標準にしました。旧・探索と疾風も選択できます。v1.5.0以前のタグ・配布物を保持します。

## 変更

- 反射の書院（光る札）、跳躍の間（上下往復）、沈み座敷（灯籠運搬）、浮遊蔵（星の保持）、逆さ回廊（光の拍子に壁天井移動）。1人で全達成でき、協力時は運搬や保持を分担できます。
- 室ごとの目標・時間・進捗・成功／失敗表示、室だけの再挑戦、全員を次へ送る歪みの扉。全体は見習い12分／忍び9分／上忍7分＋室達成ボーナス。
- ホストで試行番号・範囲・順序・拍子・二重取得を検証。水中Touchと位置同期の順序競合を修正。途中参加・切断引き継ぎ・再開始に対応。
- 障子と天井で囲われた和室、傾く梁、浮いた／逆さの畳。実形状の局所AO＋静的灯籠直接光を297万rayで再ベイク。多重反射GIではありません。
- 最後の庭で既存の木刀・HP・気力・静音着地・忍者聴覚・煙玉・牢救出を使用。環境別VC、柔らかなグロー、ブラー調整、快適移動も保持。

## 検証と制約

45単体試験、型検査、ベイク整合、実Chromiumの新ミッション一周・室再挑戦・協力運搬・重複取得・途中参加・ホスト退出と従来の探索／戦闘／音響回帰。移動位置・時間切れ・敵保護fixtureを使用し、達成・印・点数・勝利はホストが実入力／占有から生成します。無補助の人間による全歩行試験とは区別します。

Pagesはソロと同一ブラウザの最大4タブ。別端末通信やVCバックエンドは含みません。実リモート通話、VR／Android実機、指定TenTenサイト通しは未検証。Windows QA停止を維持。標準SDKでは特殊移動が足場／ワープ互換経路になります。
