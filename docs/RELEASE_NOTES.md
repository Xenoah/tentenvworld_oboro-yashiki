# 朧の屋敷 — OBORO v1.4.0

木刀・HP・スタミナを追加しました。忍者をひるませて逃げ道を作り、気力を残して五つの印を集めてください。v1.3.1の五印、特殊移動、静音着地、砂埃、照明・ベイク、難易度別の牢救出を保持しています。

## 遊び方と変更

- **木刀**：J／左下の木刀ボタン。正面100度・2.4m以内の忍者一体へ40の体勢ダメージ。3打で8秒間止まり、その後復帰。750ms間隔、22気力を消費。PvP・流血・討伐加点はありません。
- **HP100**：忍者の警告後、見習い35／忍び50／上忍100のダメージ。1.8秒の被弾保護で同時攻撃の重複ダメージを防止。HP0で見習い・忍びは牢、上忍は全員敗北。救出時にHPと気力を回復します。
- **気力100**：実走行で消費し、歩行・休止で回復。0では息切れ、30まで回復するとダッシュ可。同梱の公式クライアントにデスクトップ／XRの速度制限を実装。
- **被弾と命中の表示**：木刀・光跡・敵の体勢、HP／気力バー、被弾メッセージと画面縁。縁色は標準／弱／切。画面揺れなし、XRの画面縁は無効です。XRは右グリップ＋右トリガーで木刀、浮遊ステータスでHP確認（実機未検証）。
- **同期**：ホストが参加者・run・pose・向き・距離・遮蔽物・気力・間隔・要求番号を確認。クライアント申告の敵番号やダメージ値は採用しません。途中参加・ホスト交代・救出で共有状態を維持、再開始で初期化。

詳しい数値と互換性は `docs/COMBAT.md`、固定TenTenV commitへの適用は `docs/CLIENT_EXTENSION.md`。

ホスト交代と同時に敗北などの一度だけの更新が届いた場合、別タブが旧状態に残る競合も修正。切替後に新ホストへsnapshotを再要求し、送信者確認を維持したまま確定状態へ揃えます。順序を固定した再現テストを追加しました。

## 検証と制限

36単体テスト、型検査、既存ベイクの形状・ハッシュ一致、Pagesビルドを検査。ブラウザ試験は実際のJ／ボタン・Shift移動、共有ダメージ、HP0捕縛、仲間救出、途中参加・ホスト交代・再開始、既存五印・移動・同期回帰を含みます。敵位置・保護時間・試験区画間のteleport fixtureを使いますが、命中・HP減少・気力枯渇・捕縛・救出・勝利の成功結果は注入しません。

標準TenTenVへ`.ttvw`だけをimportした場合、局所移動は互換足場、息切れ時のダッシュ速度制限は非対応です。同梱の拡張済み公式クライアントで揃います。SDK 0.1.1 / protocol 0.1.0 / upstream `97e9bc120f4f977e0a3cfdb79379391e236f25e2`。

Pagesはソロと同一ブラウザの最大4タブ協力（BroadcastChannel）。別端末オンライン・実親サーバー・WebRTC/TURN・VR実機・実Android・公開URLでの3D通しは未検証。実行環境から公開Pagesへの接続は既存ネットワーク制限があり、CI内のローカル静的配信を検証しています。環境別の実リモートVCは次段の未完了項目です。課金・新資格情報・マイク許可は追加していません。
