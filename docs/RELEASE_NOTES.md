# 朧の屋敷 — OBORO v1.5.0

受信した相手の声を場所に合わせて加工する環境音響を、同梱の公式クライアントへ追加しました。v1.4.1の木刀・HP・気力、五印、特殊移動、牢救出と従来の照明・ベイクを保持します。

v1.4.1の救出後フィードバック修正と、低負荷の機能試験／高画質1画面撮影の分離を保持しています。

## 変更

- 部屋の残響、狭間・縁側の短い反響、水中の700Hz低域通過、屋外の乾いた声。頭位置からゾーンを判定し、180msで音色を補間します。
- 右上のVC音響ボタンでOFF。携帯端末は畳み込みなしの軽量処理。受信音声の人数と「通話なし」を表示。
- 公式のWebRTC／Opus relayの共通受信口 `VoiceManager.addRemote` に接続。既存の距離・HRTF・個別音量・ミュートを維持し、stream交換時の頭位置への再接続と旧ノードの破棄も修正。
- マイク起動・送信先・権限を変更しません。標準クライアントへのttvw単体importでは追加音響なし。「クライアント拡張が必要」と表示します。
- 描画が遅れた場合も、新しいHP減少を反映した時点で被弾の縁色と説明を表示します。途中参加や救出時のHPを被弾として再生しません。

## 実装と検証の範囲

38単体試験、型検査、ベイク整合、本番ビルド、既存一周／同期／戦闘のブラウザ回帰。実ChromiumのOfflineAudioContextで実DSP出力の周波数・尾・振幅を検査。2タブのゲームでは生成MediaStreamを受信処理へ渡し、実音声出力・ミュート・音量・ゾーン・切替・交換・破棄を検査します。

この試験は実マイク会話や別端末通信ではありません。ローカルWebRTC試験はICE候補0で成立せず、ネットワークや権限は変更していません。PagesにはVCバックエンドがなく0人／通話なしが正常です。実リモート通話・親サーバー・VR／Android実機・公開URLでの3D通しは未検証。Windows QAは停止を維持。詳しい実経路と限界は `docs/VOICE.md`。
