# 朧の屋敷 — OBORO v1.0.0

TenTenV公式テンプレートとSDKを使った忍者屋敷からの脱出ゲームです。ソロで全区画を解け、同じブラウザの最大4タブで鍵・仕掛け・勝敗を共有できます。

- 回転隠し扉、ジャンプ台、水中、無重力の蔵、壁と天井の回廊、五つの共有印。
- 忍者の巡回・追跡・攻撃予兆、捕縛/時間切れの敗北、脱出、再挑戦、3段階の難易度と得点。
- 途中参加snapshot、重複取得防止、ホストタブ退出時の引継ぎ。
- 伝統的な木造屋敷、畳・障子・瓦・庭園、自作の30枚のPBRマップと合成音。
- 特殊移動を実装した公式クライアントをPagesデモへ同梱。快適移動・自由移動、玄関への復帰、小画面UI。

PCではWASD移動、クリックで視点操作、E/クリックで調べる、Space上昇、Q下降。玄関で難易度を選んで開始します。自由移動はゲーム内の「快適移動」で切り替えます。

## 配布物

- `oboro-v1.0.0-source.zip`: 対応ソース、公式SDK/クライアント、ワールド、README、導入説明、検証方法、ライセンス。Node.js 22.13以上（24推奨）で `npm ci` → `npm run dev`。
- `oboro-yashiki-v1.0.0.ttvw`: 公式パッケージ形式のワールド。標準クライアントへの単体importでは、特殊移動は互換ワープ足場になります。局所移動には同梱クライアント拡張が必要です。
- `oboro-v1.0.0-pages.zip`: Pages用の静的デモ一式。`/tentenvworld_oboro-yashiki/` 配下へ配置する構成。file://からの直接起動には対応しません。
- `SHA256SUMS` / `RELEASE_BUILD.json`: 配布物のハッシュと、実際にビルドしたcommit。
- `LICENSE.txt` / `THIRD_PARTY_LICENSES.txt`: AGPLおよび依存・素材の帰属とライセンス。

## 検証と制限

型検査・状態機械12テスト・公式CLIの検査/梱包・公式クライアント本番ビルドを実行。Chromiumで開始から五印・特殊移動・勝敗・再開始、4タブ同期・途中参加・重複鍵・ホスト退出、小画面の開始と仮想スティックを検証しています。長い移動区間は公式debug engineのテレポートを使用し、仕掛けは登録済みの本物のClickable callback、時間切れと敵遭遇は配置/時計fixtureも使います。全行程を画面クリックだけで操作した試験ではありません。

**Pagesはソロと同一ブラウザのタブ間協力デモです。別端末間のオンライン協力・音声通信にはTenTenV親サーバー等が必要で、この静的デモには含まれません。** インターネット/WebRTC/TURN、VR実機、実Android端末の通し試験は未実施。ソフトウェアGPUの低いFPSから実GPU/Quest性能を保証しません。VRM全身の壁面姿勢や競技用不正防止にも制限があります。

`?debug=1` で明示的に開いたデモではブラウザ検証用のローカルengine参照を使えます。通常URLでは公開しません。テストfixtureはtests配下にあり、通常プレイ中に自動実行されません。秘密情報・外部のテストサービスは含みません。

公式基盤: TenTenV `97e9bc120f4f977e0a3cfdb79379391e236f25e2` / World SDK 0.1.1。プロジェクトはAGPL-3.0-only。自作素材は同ライセンス、継承したAkaneアバターはCC0、LINE Seed JPフォントはSIL OFL 1.1です。詳細は `docs/ASSETS.md` と `docs/THIRD_PARTY.md` を参照してください。
