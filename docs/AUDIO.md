# 音楽と効果音（v1.7）

下の「音：入」を押すとブラウザのユーザー操作から開始します。「音量・曲」でBGM／SEの音量・個別ミュート、雅／影の編成、自動選曲／任意曲を変更できます。再参加時は無音から開始し、許可なしの自動再生・マイク要求はしません。VRでは入口付近の3D音ボタンから音量を段階変更、0でミュートできます（実機未検証）。

各曲は8小節。雅は明るい五音音階と琴／笛／鐘、影は異なる音階・後半旋律・シンコペーション・三味線風と低い太鼓を使用します。テンポ変更だけの別版ではありません。水中は笛、浮遊蔵は鐘など主旋律の楽器も変わります。実楽器録音の再現精度を保証するものではありません。

26種×4波形のSEを用意し、同種は0→1→2→3の順に変化。砂・石・木・畳・水・特殊床の走行・離陸／着地、木刀空振り／命中、被弾、取得、扉、転移、成功失敗、警告、開始等を区別します。足音は共有された騒音イベントから位置音声として鳴らします。静音着地は引き続き無音。音量やミュートはホストの忍者聴覚判定に影響しません。

## 音声経路と後片付け

ゲームBGM／SEの独立Gain→コンプレッサー→柔らかな振幅制限→SDKのAudioListener。VC本体はこの経路を通りません。受信音声peerが1人以上ならBGM38%・SE70%へ抑制します。発話検知ではなく受信ストリーム存在による保守的な抑制です。実通話の聴き取りやすさは未検証。

曲変更は1.2秒クロスフェード、同時音楽最大2、SE最大12。SE全体25ms／同種75msの発音間隔、最大12のLRU波形キャッシュ。背景タブは音源を破棄して停止、復帰は現在の場面から開始し、遅延した音を連続再生しません。再開始は発音中ノードと直前変奏を初期化。ワールドunmount／退出では全ノード・キャッシュ・監視イベント・タイマーを破棄します。SDK共有AudioContextは閉じません。

## 生成・配布

`npm run render:audio` は同じ合成器から `assets/audio-preview` に音楽72秒（18編成×4秒）、SE約79秒（104音）、曲目・時刻・全ループの波形統計とハッシュを保存します。`npm run check:audio` は再生成結果と保存ファイルをバイト比較。実行時のゲームは合成波形を必要な時だけ生成し、試聴WAVのダウンロードは不要です。

旋律・合成器・試聴WAVはオリジナル、AGPL-3.0-only。新依存、音源購入、外部AI/API、新権限はありません。Pagesの試聴プレイヤーとReleaseの2WAV／AUDIO_PREVIEW.jsonから取得できます。

## 検証範囲

全18ループの非無音・有限値・ピーク・循環境界・別曲／別編成の相違、全104SEの相違と始終端を単体検査。実Chromium OfflineAudioContextで同じBGM／SEバス・コンプレッサー・振幅制限を通し、2曲＋12SEの重畳をレンダリング。初回はピーク1.198を検出し、最終経路で約0.705に修正。個別音量とVC抑制時の実波形も比較します。

実AudioContextで発音変奏・連打制限・クロスフェード上限・背景停止・復帰・再開始・disposeを確認。ゲーム画面ではユーザー操作前無音、操作後の再生、自動選曲・編成変更・BGMとSEの独立ミュート、背景イベントfixture、実再開始とreloadを検証します。撮影時は最終ビルドの実再生状態をSCREENSHOTS.jsonへ記録。

数値レンダリング検査であり、人間による聴感評価・実スピーカー・VR／Android・実リモート通話の検証ではありません。Windows指定サイトQAの停止を維持。Pagesの別端末通信／VCバックエンドは追加していません。
