# 歪みの部屋（v1.6）

標準モードは屋内開始、5室を順番に達成、最後に既存の庭で忍者を避け南の門へ。旧・探索と疾風は開始画面に残しています。

| 室 | 操作・成功条件 | 協力 |
| --- | --- | --- |
| 反射の書院 | 光る札を1/2/3キー・画面ボタン・3D札で5回。1拍1回、空振りで連続回数リセット、3回空振りで室失敗 | 誰でも叩ける。早押し連打は共有失敗になるので分担を相談 |
| 跳躍の間 | 床→高台→床→高台の4印へ順番に着地。快適移動なら跳躍台がワープになる | 仲間が次の高台・床を担当可能 |
| 沈み座敷 | 灯籠4個を水底から岸の受け台へ。1人1個 | 別々の灯籠を同時運搬。切断時の荷物は元の場所へ戻る |
| 浮遊蔵 | 星の中心に見習い2／忍び3／上忍4秒静止。未完の保持は離れると減衰、達成済みは保持 | 最大3地点を分担できる。ソロは順に保持 |
| 逆さ回廊 | 光の拍子に壁→天井→奥の印へ。影の拍子は待機 | 誰かが次の印を踏めば共有で進む |
| 夜風の庭 | 5室達成で開放。忍者を避け南門の輪に触れる | 木刀・煙玉・牢救出・HP・気力を使用 |

## 時間・失敗・復帰

全体は見習い720／忍び540／上忍420秒。室達成ごとに30秒（上忍20秒）加算。室内は別の短い制限時間（35〜125秒）があり、失敗してもゲーム全体は終わりません。再挑戦は現室だけ初期化、前の印は保持、50点×難易度倍率の減点、全体の時計は継続します。主催者は途中でも再挑戦可、失敗後は参加者も操作可。全体時間切れは全員敗北。

達成後は開いた扉に近づいて押すと全員が次へ進みます。部屋移動・再挑戦・復帰時は床方向へ戻し、泳ぎ／浮遊／壁天井の移動状態を解除。暗転で遷移し、VRでは視点を強制回転しません。現室の外へ落下した場合も入口に戻します。最後の庭へ出た直後は10秒の保護があります。

## 共有状態と判定

`missions.ts` のホスト所有状態に室番号、試行番号、開始／期限、進捗、失敗、運搬、星保持、再試行数を保存。クライアントは操作と試行番号だけを送信し、完了・点数・位置をコマンドに入れません。既存ラン番号・参加者・距離検証に加え、現在室・試行・拍子・順序をホストで検証します。古い要求、遠隔操作、旧探索の印コマンドは進行に使えません。

水中の接触はホストが受信した姿勢からも検出します。Touchイベントが位置パケットより早く到着しても正当な取得を失わず、取得済み／運搬中の灯籠は再取得できません。室達成の印・加点は一度だけ。途中参加とホスト引き継ぎは既存SDKの共有snapshotと選出に従い、試行状態を継承します。既存の姿勢報告を信用する開発デモであり、対戦サーバー級の移動チート防止ではありません。

## 描画と標準クライアント

障子・天井・傾いた梁・逆さの畳と4灯を追加。`npm run bake` は2,974,064本の光線で実形状の局所AO＋静的灯籠直接拡散光を計算し、1,437,588byteの頂点RGBAを保存します。多重反射GIや全光源のベイクではありません。描画設定とグローのOFFを保持。

同梱クライアントは本物の泳ぎ・浮遊・局所重力移動。optional locomotionのない標準SDKでは足場・ワープ経路を使用します。ttvwだけで標準クライアントのコードを変更するものではありません。VC拡張と実通話の制約は [VOICE.md](VOICE.md)。

## 検証の読み方

単体試験は状態遷移・順序・二重取得・古い要求・切断を検査。実Chromium試験では入力、Touch、ホストの占有判定から各室を達成させ、完了・印・得点・勝利を注入しません。ただし長い移動の位置fixture、室時間切れfixture、敵から保護するfixtureを使用します。別の通常移動試験では位置・進行・時計・敵保護を注入せず、実WASD・泳ぎ・足場で5室から門まで通過しています。カメラ方位の設定と、近い壁位置から天井ボタンの登録callbackを1回呼ぶ補助があり、全行程を人間が無補助で操作した試験とは区別します。ソフトウェアGPU上の速度を実GPU性能とはみなしません。

同一ブラウザの2タブ協力、旧モードの4タブ同期、携帯レイアウトのエミュレーションを検証対象とします。公開TenTen指定サイトのアップロード／Windows QAは停止中。実VR・Android実機・別端末通信・実マイク通話は未検証です。スクリーンショットは実ビルドで撮影し、SHA・画質・位置・fixtureを `SCREENSHOTS.json` に記録します。
