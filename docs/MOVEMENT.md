# v1.2 身のこなしと音

Shift＋移動でダッシュ、Spaceでジャンプ。下降中、足元が着地点から約75cm以内で **X** または画面の「静音着地」を一度押します。ボタンが緑になった時が目安です。早押しはその跳躍ではやり直せず、押し忘れと同じく足音が出ます。成功時は「静音着地 成功」、失敗時は「足音が響いた」と次の跳躍まで表示します。XRでは右コントローラーのBに相当するsecondaryボタンへ割当済みですが、実機操作は未検証です。

「映像」の移動ブラーは初期28%、0でOFF、最大60%。中心の照準付近を保ち、画面周辺を進行感のある方向へ少量ぼかします。ダッシュと通常重力の跳躍だけに連動し、水中・無重力・壁歩き・ワープには適用しません。XR・携帯端末・低い描画倍率・浮動小数点描画非対応ではOFFです。速度や難易度には影響しません。カメラの揺れやロールは追加していません。

## 音から忍者へ

主催者がSDKの参加者姿勢を観測し、移動・床材・離陸・着地・入力受付を判定します。音の座標・音量・床材をクライアントから申告するAPIはありません。Xの要求は送信者本人、現在のrun、探索中、有効な空中姿勢、距離、入力済みかを照合します。判定は下降中かつ着地まで75cm以内。受理した構えは同じ跳躍の接地まで保持し、静音着地の聴覚半径は0です。歩行は静か、ダッシュは約440ms以上の間隔で足音が発生します。

失敗着地の半径は落差から8〜18m、走行は床材に応じ4〜10m、離陸は3〜5m。岩や衝立で0.55倍、室内・縁側からは0.65倍、高所からは0.6倍に減衰します。これはゲーム用の近似です。忍者は視認を優先し、見えていない場合は聞いた地点へ向かって約6.5秒捜索します。部屋の奥へ侵入しないよう目標を中庭に制限します。出現保護中の参加者の音では追跡を開始しません。

足音は自作の短いノイズ波形を既存AudioListenerへ接続したPositionalAudioで再生します。「音：入」で有効になり、距離で減衰します。**音をミュートしても忍者の聴覚は変わりません。** マイクやVCではなく環境効果音です。VC音響は後続版の対象です。

## 砂と同期

中庭の枯山水は細粒の**砂地**として扱い、走行・離陸・着地の時だけ薄茶の砂埃が立ちます。既存の色・法線・粗さファイル名 `gravel` は互換性のため維持していますが、素材の細粒ノイズと筋目を砂として使用しています。論理表面名と画面表示は `sand`／「砂」に統一。飛石・灯籠台・岩・畳・板床・水中・特殊空間では砂埃を生成しません。

砂埃はホストが確定したイベントから各端末が生成し、最大160粒、追加1 drawです。ネットワークで粒ごとの位置を送りません。受信済みIDと時刻で二重再生・途中参加時の古い再生を防ぎます。ゲーム状態は最大4人の動作履歴、直近16イベント、忍者の捜索状態を含むsnapshot。退出時に動作履歴を削除し、再開始で騒音・入力・着地・粒子・ブラーをリセットします。既存のホスト交代で履歴を引き継ぎます。

SDKのPlayerPoseにはoptionalの `speed` を追加し、既に公式pose protocolが送信している水平速度を公開します。protocol形式の変更はありません。標準SDKでこの値がない場合は位置差から推定します。通常の送信者・距離・連打・再送検証は行いますが、元からクライアント側の姿勢を使う協力ゲームです。改造クライアントの姿勢捏造や入力マクロを防ぐサーバー権威型のアンチチートではありません。参加者は全員同じ公開版を再読込してください。

## 検証

`npm run test:movement` は実ChromiumでShift移動、Space跳躍、タイミングを合わせたX、押し忘れ、砂と飛石の比較、忍者の捜索、ブラーOFF、音声ノード再生、再開始を検査します。長距離の移動はdebug teleport、敵の聴覚の分離は配置と時計・保護期間のfixtureを使います。着地結果・音・敵のmodeを直接成功値に書き換えていません。最終画像も同じ本番ビルドを動かして撮影し、コミット・表示条件・fixtureをSCREENSHOTS.jsonへ記録します。公開URLでの3D通し・別端末通信・VR実機は従来通り未検証です。

`tests/movement-sync.mjs` は同一ブラウザの実3タブで、ゲストの実走行から生成されるイベントの一致、途中参加の履歴、古い粒子の非再生、偽造/古い入力の拒否、ホスト交代と再開始を検査します。同期の分離用に出現保護期間だけを延ばすfixtureを使い、イベント自体は主催者の実姿勢観測から生成します。
